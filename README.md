# Игра "Три в ряд" (январь 2020)

## Идея

Программная реализация собственной десктопной версии игры "Три в ряд" с несколькими уровнями сложности. Цель игры состоит в том, чтобы собирать по три и более шарика одного цвета в вертикальные или горизонтальные линии, после чего шары исчезают и на их месте появляются новые. Шарики расположены в клетках доски. Изначально все клетки закрашены. Игра заканчивается, когда с поля удаляются все закрашенные клетки, уничтожающиеся при исчезновении шарика, находящегося в закрашенной клетке.

## Цель

Данный проект написан в рамках учебы в Яндекс Лицее. Целью выполнения работы было получить опыт в разработке своего цельного проекта, потренироваться в разработке простой игры на Python с использованием PyGame: разобраться с устройством игрового цикла, обработкой событий, отрисовкой, работой со структурами данных и алгоритмами поиска совпадений, а также получить опыт разбиения кода на функции и организации логики проекта.

## Стек

- Python
